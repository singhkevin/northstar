# Northstar website

Website for **Northstar**, which works on physical AI: autonomous drones, quadruped and humanoid robots, and connected industrial systems.

It's a static site: plain HTML, CSS and JavaScript, with no framework and no build step to serve it. Everything the website serves is in `site/`.

- **Live site:** https://northstar.viralinbound.in
- **Preview:** https://northstar-khujinxxc-viral-inbound.vercel.app
- **Hosting:** Vercel, project `northstar`, team `viral-inbound`

## Run it locally

You need Node.js to run the local server, and Python 3 to rebuild the inner pages.

```bash
git clone https://github.com/singhkevin/northstar.git
cd northstar
npx http-server site -p 8080 -c-1
```

Then open http://localhost:8080.

Always serve the `site` folder as the web root. The pages use root paths such as `/media/...`, so opening `index.html` straight from disk won't work.

### Editing the inner pages

Each inner page is a short page head, followed by sections taken from the home page. **Don't edit the generated pages by hand.** Change `site/index.html`, or the page list in `tools/build_pages.py` (titles, intro lines, which sections each page shows), then run:

```bash
python3 tools/build_pages.py
```

Commit the home page and the regenerated pages together.

## Project structure

```
site/                  the website (deploy this folder)
  index.html           home page: styles, markup and main script are inline
  platform/ technology/ solutions/ industries/ about/ contact/
                       inner pages, generated by tools/build_pages.py
  drone.js             3D drone that flies between home-page sections (three.js, minified)
  terrain.js           3D terrain in the Platform section (three.js, minified)
  vendor/              GSAP, ScrollTrigger and Lenis (smooth scroll), self-hosted
  media/               images, video loops (*-s.mp4 = phone versions), drone.glb
  brand/               logo files used by the site, plus the /brand/ page
  vercel.json          noindex header, media caching, redirects
tools/build_pages.py   builds the inner pages from the home page
brand/                 logo files (SVG/PNG), originals in brand/source/
docs/                  brand guidelines, approved copy, founders' copy (PDF)
```

## Things to know

- **Copy:** all text is the founders' approved copy (`docs/COPY.md`, `docs/source/`). Don't add claims, numbers, client names or testimonials. Sample data shown on the page is labelled "Illustrative".
- **Brand:** colours, type and logo usage are in `docs/BRAND-GUIDELINES.md`. Fonts are Sora, Inter and JetBrains Mono (Google Fonts).
- **Media caching:** `/media/` is served as immutable for a year. To replace a file, upload it under a new name and update the reference; don't overwrite it.
- **3D files:** `drone.js` and `terrain.js` are prebuilt, minified bundles. Edit them with care and test the home page afterwards. The drone is only loaded on the home page. The terrain is loaded on the home page and `/platform/`.
- **Search engines:** the site currently sends `noindex, nofollow` (`vercel.json` and a meta tag in each page). Remove both when it's ready to be indexed.
- **Contact:** "Talk to our team" links to the contact section at the bottom of each page. There's no form yet.

## Publishing

The site is published with the Vercel CLI from the `site/` folder. You need access to the Vercel team `viral-inbound`.

```bash
cd site
npx vercel link --yes --project northstar --scope viral-inbound   # first time only
rm -f .env.local                                                  # vercel link creates this; never publish or commit it
npx vercel deploy --yes --scope viral-inbound                     # preview
npx vercel deploy --prod --yes --scope viral-inbound              # live site (with Kevin's go-ahead)
```

To roll back, open the Vercel dashboard, choose the earlier deployment and click "Promote to Production" (or run `vercel rollback`).

Never commit keys or `.env` files; `.gitignore` already excludes them.
